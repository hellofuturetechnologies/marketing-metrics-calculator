# Marketing Metrics Calculator

[Use the free tool](https://hellofuturetechnologies.github.io/marketing-metrics-calculator/)

Enter campaign totals from the same reporting period and click **Calculate metrics**. Choose the currency used for both spend and attributed revenue. Leave unavailable totals blank. The calculator displays a dash when a metric cannot be calculated.

| Metric | Formula |
| --- | --- |
| Click-through rate (CTR) | Clicks ÷ impressions × 100 |
| Cost per click (CPC) | Spend ÷ clicks |
| Cost per thousand impressions (CPM) | Spend ÷ impressions × 1,000 |
| Cost per lead (CPL) | Spend ÷ leads |
| Cost per acquisition (CPA) | Spend ÷ conversions |
| Click-based conversion rate | Conversions ÷ clicks × 100 |
| Return on ad spend (ROAS) | Attributed revenue ÷ spend |

**Load example** fills in a synthetic campaign with a CTR of 2.50%, a CPC of PKR 20.00, and a ROAS of 4.00×. Currency is a display label. The calculator does not convert currencies.

Open `index.html` to run a local copy. No build, dependencies, or sign-in are required. The page does not upload campaign inputs.
